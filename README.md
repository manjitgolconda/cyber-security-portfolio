## 🚀 Getting Started

### Local Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/manjitgolconda/cyber-security-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd cyber-security-portfolio
   ```
3. Open `index.html` in your favorite browser or serve locally:
   ```bash
   python -m http.server 3000
   ```
4. Access the live interface at `http://localhost:3000`.
